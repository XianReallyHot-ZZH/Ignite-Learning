# 探索 ignite 源码库

## 学习路径探索
深入阅读分析 @vendors/ignite 源码，在完全掌握 ignite 源码后，对 ignite 进行子模块划分，制定子模块的学习路径（顺序），充分考虑以下几点：
- 子模块的顺序合理性，模块之间的衔接性
- 子模块实现上的依赖关系，初学者的学习曲线。
- 内容划分是否合理（内容过大或者过小）
- 所有子模块加在一起，内容是否完整（包含了Ignite所有核心功能）
- 最终沿着该顺序，初学者是否能成功实现一个功能完整的 Ignite 项目
一句话记住：最好的教学顺序，不是源码文件出现的顺序，而是一个初学实现者真正能顺着依赖关系把系统重建出来的顺序。
最终要求：初学者沿着该学习路径，能够从零到一手搓实现完整的 Apache-Ignite 项目。
把学习路线写到 @specs/ignite-complete-learning-roadmap.md 文件中，如果一次性写入内容太多，可以分多次写入。
